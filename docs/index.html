solana-token-meta

Solana token metadata and rug check, from one RPC call

Which token program a mint uses (SPL Token or Token-2022), decimals, supply, mint and freeze authority, every Token-2022 extension, and the name, symbol and uri from either the Token-2022 metadata extension or Metaplex. One getMultipleAccounts call, works on the free public RPC. Zero dependencies.

Pass several mints at once, --uri to fetch the off-chain JSON (image, description, socials), --json for the full result.

What it does

  • Mint and freeze authority, with null meaning revoked
  • Token-2022 extensions decoded: transfer fee (the one in force now), permanent delegate, transfer hook, metadata pointer, token metadata, default account state, pausable and more
  • Name, symbol and uri from Token-2022 or Metaplex, whichever the mint uses
  • Risk flags that only state facts: mintAuthorityActive, freezeAuthorityActive, metadataMutable, hasTransferFee, hasPermanentDelegate, hasTransferHook
  • 50 mints per RPC call in batch mode
  • Offline decoding of accounts you already fetched

Use it in your code

npm install github:blixvip/solana-token-meta
import { getTokenMetas, riskFlags } from "solana-token-meta";

const metas = await getTokenMetas([
  "DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263", // BONK
  "EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v", // USDC
  "DxYWLXgKJpQmfhTG7ikK6oX6oDhxMhN5wCs5BJekpump", // a pump.fun coin on Token-2022
]);
for (const m of metas) {
  const f = riskFlags(m);
  console.log(m.metadata?.symbol, m.program, "mint:", f.mintAuthorityActive ? "ACTIVE" : "revoked", "freeze:", f.freezeAuthorityActive ? "ACTIVE" : "revoked", "metadata mutable:", f.metadataMutable);
}

DEED token-2022 mint: revoked freeze: revoked metadata mutable: false
